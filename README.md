# Suno AIアルバムスタジオ スキル集

アルバムの企画から一曲ずつの制作、全曲完成後の紹介文までを支援する、8種類のエージェントスキルです。

まず「企画部」で世界観や音楽性、曲ごとの役割をまとめた**アルバム企画書**を作り、それを「制作部」に渡して、Suno向けの歌詞やスタイルプロンプトを作ります。「企画アシスタント」では、企画書の説明・分析・修正・正規化もできます。

音楽や画像そのものを生成するアプリではなく、Sunoや画像生成AIへ渡すテキストを作るための指示・参考資料・検査スクリプトをまとめたものです。

## ダウンロード

**このリポジトリの「Releases」から「Latest」のReleaseを開き、Assetsにある目的のスキルのZIPをダウンロードしてください。**

- 最新Releaseには、その時点の全8スキルの最新版ZIPを個別に掲載します。差分配布ではありません。
- 必要なスキルだけを導入できます。すべて揃える場合は8個のZIPを個別に取得してください。一括ZIPは提供しません。
- ZIP名とバージョンは、[配布内容一覧](RELEASE_CONTENTS.md)で確認できます。
- **「Source code (zip)」「Source code (tar.gz)」やCodeメニューの「Download ZIP」は、インストール用スキルではありません。** `suno-album-studio-`で始まる個別ZIPを選んでください。

ここは配布専用リポジトリです。Code側には案内と配布内容一覧を置き、インストール用ZIPはReleasesに掲載します。開発用の知識DB、ビルド環境、テストログは含めません。実行に必要な参考資料・スクリプトは各ZIPに同梱しています。

## まず何を使うか

迷った場合は、**「総合企画部」＋「制作第2部」**から始められます。企画書を必要に応じて整えたい場合は「企画アシスタント」を追加してください。

1. **企画する**：企画部を一つ選び、対話しながらアルバム企画書を作ります。
2. **必要なら整える**：企画アシスタントで内容を確認・修正します。この工程は任意です。
3. **一曲ずつ制作する**：制作部または制作第2部に企画書の全文を渡し、曲ごとに確認・修正しながら進めます。
4. **Sunoで音楽にする**：出力された歌詞・Styles・Exclude StylesをSunoへ貼り付けます。全曲分のテキストが完成したら、制作部でアルバム紹介文やジャケット用プロンプトも作れます。

企画部と制作部の間で、チャットの内容が自動共有されるわけではありません。別のチャットで制作する場合も、完成した企画書を保存して全文を渡してください。

## スキルの選び方

### アルバムを企画する

各企画部は、**企画の入り口が異なる独立したスキル**です。番号は新旧や作業順序を表しません。順番に使う必要はなく、第3部は配布対象にありません。

| スキル | 企画の決め方・向いている用途 | スキル名・ZIP名の先頭 |
|---|---|---|
| 総合企画部 | 最初に5人の企画者を提示し、A：一人の企画者と相談、B：お題で企画コンペ、C：音楽を聴きたい場面、D：自分のアイデア、の4通りから選べます。後半は共通の音楽設計フローです。 | `suno-album-studio-planning` |
| 企画第1部 | 自分のテーマ、世界観、ジャンルなどの希望を出発点に、王道案と派生方向を相談して企画を決めます。 | `suno-album-studio-planning1` |
| 企画第2部 | 5人の企画者から一人を選び、その企画者が提案する5つのアルバム案を比較して決めます。 | `suno-album-studio-planning2` |
| 企画第4部 | リスナーの「音楽を聴きたい場面」を選び、音楽性と世界観を組み立てます。 | `suno-album-studio-planning4` |
| 企画第5部 | 提示されたお題、または自分のお題を選び、5人の企画者が一つずつ出すアルバム案を比較して決めます。 | `suno-album-studio-planning5` |

総合企画部は4種類の入り口をまとめた選択肢です。既存の個別企画部を利用したい場合は、そちらだけを導入できます。総合企画部が個別企画部を呼び出す仕組みではなく、他の企画部のインストールは不要です。

企画者・リスナー・音楽プロデューサーのペルソナは、異なる視点から案を作るために使います。人物になりきった会話を楽しむ形式ではなく、候補の比較と選択を中心に進みます。

企画部では、アルバムの中心となる音楽性と、曲ごとのジャンルの広がりも扱います。「大きく変化」は音量やテンポだけの変化ではなく、曲ごとに主役となるジャンルを広げる方向です。具体的な希望があれば、残したい共通性と試したいジャンルを伝えてください。

### 企画書から曲を制作する

| スキル | Stylesの形式 | スキル名・ZIP名の先頭 |
|---|---|---|
| 制作部 | 音楽設計を項目別に示す、構造化8行形式 | `suno-album-studio-production` |
| 制作第2部 | 音楽設計を自然な英文でまとめる、散文形式 | `suno-album-studio-production2` |

どちらも同じアルバム企画書を受け取れます。主な違いはStylesの形式であり、制作第2部が制作部の次の工程という意味ではありません。好みの一方を選んでください。

共通して、一曲ごとに次を作ります。

- 曲名
- 漢字かな交じりの歌詞と、発音を考慮したAI歌唱用歌詞
- 英語のStylesとExclude Styles
- 画像生成AI用プロンプト4案

一曲ずつ承認・修正し、次の曲へ進みます。全曲分のテキストの承認後、完成処理を依頼すると、アルバムタイトル候補、曲順、全体・各曲のライナーノーツ、紹介文、ハッシュタグ、ジャケット用プロンプトも作ります。

歌詞のモーラ数やパートごとの行数、Stylesの文字数などをコードで検査します。ただし、発音や意味、音楽としての出来まで機械的に保証するものではありません。制作時には検査・修正のために時間がかかる場合があります。

### 企画書を分析・加工する

| スキル | 主な用途 | スキル名・ZIP名の先頭 |
|---|---|---|
| 企画アシスタント | 企画書の要約・説明・分析、部分修正、欠損の補完、正規化、完全版の再出力、仮ライナーノーツの作成 | `suno-album-studio-planning-assistant` |

正規化は、制作上の大きな問題を拾って整える機能です。企画固有の世界観や音楽性を保ちながら、歌詞テーマの過剰な詰め込み、重要な欠損などを扱います。軽微な表現の違いまで一律に直し続ける用途ではありません。

処理内容を直接指定しても、「この企画書について相談したい」「何ができますか？」から始めても構いません。企画書に基づく仮ライナーノーツは作れますが、実際の音源を聴いた評価ではありません。アルバムスタジオ各製品の案内や、完成歌詞・Stylesの制作は担当しません。

## 導入と使い方

1. 最新Releaseから、利用したいスキルの個別ZIPを取得します。
2. 利用環境のスキル追加・読み込み機能で登録します。ZIPアップロード対応の環境では、そのZIPを指定してください。
3. 対象スキルを選んだ新しいチャットで、希望や入力資料を送ります。
4. 選択・承認・修正のやりとりを行い、完成した企画書や曲のテキストを保存します。

企画書は、全文をチャットへプレーンテキストで貼り付けるか、TXT・Markdownのテキストファイルで渡してください。PDF・DOCXへの変換は不要です。

### 最初の依頼例

- 総合企画部：「アルバムを企画したいです。まず作り方を選ぶところからお願いします」
- 企画第1部：「引っ越し前夜の寂しさと期待をテーマに、4曲のミニアルバムを考えたい」
- 企画第5部：「お題から選んでアルバムを企画したい」
- 制作第2部：「このアルバム企画書を使って、1曲目から制作を始めてください」
- 企画アシスタント：「この企画書を制作部へ渡す前に確認し、大きな問題があれば正規化を提案してください」

対象スキルを選んだうえで依頼してください。制作・企画書の加工では、企画書の全文も添えてください。スキル名の明示方法は利用環境によって異なります。

## 実行環境について

ChatGPT Workでの利用を中心に開発・実地確認しています。スキルの参考ファイルを読み取り、同梱のPythonスクリプトを実行できるエージェント環境が必要です。

移植しやすいよう、指示・参考資料はテキストで構成し、特定PCの固定パスや外部APIへの接続を前提にしていません。各スキルは必要な資料を同梱しており、単曲系スキルや他のアルバムスタジオスキルを実行時の依存先にしません。

開発者による他環境での利用例もありますが、すべてのサービス・モデル・プランでの互換性を保証するものではありません。登録方法、コード実行、ファイル出力、利用料金や使用量の扱いは利用環境によって異なります。

**通常のチャットでスキル名を伝えるだけでは、スキルが実際に読み込まれたことにはなりません。** 参照ファイルやスクリプトへアクセスできない環境では、本来の工程を実行できません。「コード実行未確認」「検査未合格」などが表示された場合も、検査済みとして扱わないでください。

## 更新の考え方

- Release名は日付を基準にし、いずれかを更新した場合も、全8スキルの最新版ZIPを同じ新Releaseに揃えます。
- Releaseの日付と個々のスキルのバージョンは別です。変更のないスキルは同じバージョン・同じZIPを再掲載します。
- 最新版を揃える場合は最新Releaseだけを参照してください。同じバージョンのスキルは更新不要です。
- ダウンロードだけでは登録済みスキルは更新されません。利用環境の更新手順に従い、更新後は新しいチャットで確認してください。

変更点は各Release本文、版とZIP名は[配布内容一覧](RELEASE_CONTENTS.md)に記載します。

## 関連スキル

## 注意事項

- SunoおよびOpenAIの公式製品ではありません。
- 出力は利用モデル、入力、設定、各サービスの変更によって変わります。指示どおりの音楽や画像になることを保証するものではありません。
- 最終的な歌詞・発音・音楽性は、Sunoでの結果も含めて確認してください。
- 音楽・画像の生成やSunoへの送信はユーザーが別途行います。各サービスの利用権は付属しません。
- ローカルで動く検査スクリプトが含まれますが、AIサービス自体のオフライン動作を意味しません。入力資料は利用するAIサービスへ渡されるため、共有してよい内容か確認してください。
